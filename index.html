Reclaim locked SOL

Every empty token account holds a small SOL deposit. Closing it sends that SOL back to you. Nothing else is touched.

Active approvals

These token accounts have a delegate — someone you (or an app) approved to move your tokens. A personal wallet holding approval over your tokens is a red flag. Revoke anything you don't recognise.

Your tokens

Risk ratings come from live market data and on-chain token settings. Tick junk tokens to burn them and reclaim their SOL deposit.

Swap

Best-price routing across Solana DEXs, powered by Jupiter. OnTrace checks the token you're buying before you swap. Mainnet only.

Multi-send

Send SOL or any token to many wallets at once — airdrops, team payments, giveaways. Recipients without a token account get one created automatically (you pay the small deposit).

Create a token

Launch a Solana token (Token-2022 standard) with its name and symbol stored on-chain. Safe defaults: tokens can never be frozen, and the supply can be locked so no more can ever be minted.

What goes in the metadata link?

Host a small JSON file (for example on your own site) so wallets and explorers show your logo:

{
  "name": "OnTrace",
  "symbol": "ONTRACE",
  "description": "The Solana toolbox.",
  "image": "https://ontrace.space/logo.png",
  "external_url": "https://ontrace.space"
}

Freeze authority is never set, so nobody — including you — can freeze holders' tokens.

Token checker

Paste a token's mint address before you buy. OnTrace checks its market, liquidity and creator permissions.

Trending on Solana

Tokens getting attention on DexScreener right now. Boosted means the team paid for promotion — not the same as organic demand. Always check before buying.

Wallet watchlist

Follow any wallet — whales, devs, smart traders, your own. Saved in this browser only.

Watched wallets

Live alerts

Get notified when a watched wallet makes a move. Alerts run while OnTrace is open in a browser tab (round-the-clock alerts via a Telegram bot are coming later).

Developer wallet tracker

Find who created a token, how much they still hold, whether they've been selling, and how concentrated the top holders are.

Wallet relationship graph

See who a wallet trades and transfers with most. Click a node to explore that wallet next. Off-curve addresses are programs or pools, not people.

Transaction inspector

Paste a transaction signature to see what happened in plain English, or paste an unsigned transaction (base64) to simulate it and see exactly what would change before anyone signs. Flags drainer patterns like handing over token-account ownership.

RPC endpoint

Solana's free public server blocks websites on mainnet. Paste a free RPC URL (e.g. from Helius) for reliable use. Saved only in this browser.

Priority fee

Small tip to validators so transactions land faster when the network is busy.

Transparency. OnTrace runs entirely in your browser and never asks for your seed phrase. Every transaction is shown in your wallet before you approve it. Cleanup uses only standard Solana Token Program instructions (close, burn, revoke). Swaps are routed by Jupiter; market data comes from DexScreener. OnTrace charges no fees. Risk ratings are automated signals, not financial advice — always do your own research.
